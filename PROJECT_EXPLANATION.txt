1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
SkillNexus is a full-stack, production-grade autonomous verification platform
designed to fundamentally replace self-reported student resumes with an automated,
multi-source evidence verification loop.

In traditional placement ecosystems, students submit unverified claims (keyword-
stuffed PDFs), colleges lack visibility into real industry skill requirements,
and employers spend hundreds of hours conducting basic screening interviews to
weed out exaggerated resumes.

SkillNexus solves this problem by building a "Ground-Truth Evidence Engine" that
continuously validates competencies across 4 distinct evidence sources:
  1. Cryptographically verified academic certificates (OCR + tamper scanning)
  2. Live GitHub codebase telemetry (AST analysis, commit cadence, DevTier rank)
  3. Timed sandbox challenges (live in-browser code execution for SQL & algorithms)
  4. Real-world industry bounties (48-hour pull request submissions)

All evidence feeds into a deterministic, weighted Aggregate Readiness Engine that
outputs a real-time readiness score and a multi-dimensional Dynamic Skill Radar.

3. THE 11 CORE MODULES / PILLARS
--------------------------------------------------------------------------------

MODULE 1: CERTIFICATE AUTHENTICATOR (OCR & ANTI-TAMPER ENGINE)
  • Allows students to upload PDFs/images of certificates (NPTEL, Coursera, AWS, etc.).
  • Performs client-side & server-side OCR simulation to extract student name,
    issuing authority, date, and awarded skills.
  • Runs heuristic anti-tamper detection: inspecting PDF producer metadata,
    Photoshop modification timestamps, font embedding anomalies, and issuer
    registry checksum verification.
  • Generates a cryptographic verification hash and assigns an authenticity
    confidence score (0-100%).

MODULE 2: GITHUB GROUND-TRUTH ANALYZER (TELEMETRY & DEVTIER)
  • Connects directly to the GitHub REST API (https://api.github.com/users/{handle})
    with graceful fallback to deterministic simulation if rate-limited.
  • Extracts real public repositories, star counts, commit velocity, and language diversity.
  • Analyzes code AST patterns to verify production-grade practices (async/await,
    database connection pooling, error boundaries, TypeScript usage).
  • Categorizes developers into 4 verified tiers:
      - Novice
      - Intermediate
      - Advanced
      - Elite Architect

MODULE 3: DYNAMIC SKILL RADAR & AGGREGATE READINESS ENGINE
  • Visualizes student competency across 6 dimensions: Frontend, Backend,
    Cloud/DevOps, AI/ML, System Design, and Database.
  • Features a live overlay comparator against specific employer benchmark profiles
    (e.g., Razorpay Backend Intern, Zerodha Go Developer).
  • Implements the SIH Ground-Truth Weighted Readiness Formula:
      Readiness Score = (0.40 * Avg Verified Skill Score) +
                        (0.25 * GitHub Telemetry & AST Score) +
                        (0.20 * Tamper-Proof Cert Confidence) +
                        (0.15 * Completed Industry Bounty PRs)

MODULE 4: DYNAMIC BRIDGE PATHWAYS (5-DAY ACCELERATED SPRINTS)
  • Identifies the exact skill gap between student's verified radar and target
    internship requirements.
  • Automatically scaffolds a personalized 5-Day micro-curriculum:
      - Day 1: Foundational architectural documentation & reading
      - Day 2: Implementation of core mechanics
      - Day 3: Edge cases, error boundaries & resilience
      - Day 4: Production benchmarking & profiling
      - Day 5: Verification challenge submission to close the gap

MODULE 5: SKILL CHECK SANDBOX (TIMED IN-BROWSER IDE)
  • A 3-minute high-pressure timed coding sandbox where students solve real-world
    engineering challenges (e.g., Redis rate limiting, SQL connection pool contention).
  • Features live monospace syntax editor, countdown timer, keyword pattern matching,
    and automatic test-suite validation.
  • Immediately credits verified skills to the student's profile upon test passage.

MODULE 6: GAP-TARGETED AI MOCK INTERVIEWER
  • Evaluates students specifically on the skills where their radar falls below
    the employer benchmark.
  • 3-stage conversational interview flow with live microphone speech input simulation,
    technical transcription, and automated evaluation metrics:
      - Technical accuracy & conceptual mastery
      - Communication clarity & articulation
      - Production architecture awareness

MODULE 7: INDUSTRY BOUNTY BOARD (48-HOUR SPRINTS)
  • Employers post real engineering bug fixes and feature requests with cash grants
    and pre-placement interview (PPI) / CTC booster rewards.
  • Students claim challenges and submit GitHub pull request links.
  • The verification engine runs auto-grading on branch coverage, AST style compliance,
    and code cleanliness to award points and grants.

MODULE 8: CAPSTONE & HACKATHON TEAM MATCHMAKER
  • Solves team composition failures using a greedy heuristic matchmaker algorithm.
  • Analyzes students' verified skill vectors and pairs complementary profiles
    (e.g., pairing a Backend/Cloud specialist with a Frontend/UI designer).
  • Calculates team synergy percentages and provides direct team invite workflows.

MODULE 9: TAMPER-PROOF CRYPTOGRAPHIC LETTER OF RECOMMENDATION (LOR)
  • Faculty and mentors issue digitally signed recommendation letters.
  • Every LOR is hashed using SHA-256 and anchored with cryptographic metadata
    (student ID, faculty designation, institution name, timestamp).
  • Provides a public verification receipt and QR-code proof link that anyone can
    independently verify.

MODULE 10: REAL-TIME MARKET DEMAND RADAR
  • Aggregates live hiring demand trends across Indian tech hubs (Bengaluru,
    Hyderabad, Pune, NCR).
  • Tracks surging vs. declining technologies (e.g., Rust, Next.js, Kubernetes vs. PHP).
  • Displays time-series demand charts and curriculum misalignment alerts for colleges.

MODULE 11: PUBLIC PROOF PORTFOLIO
  • A shareable, public profile link (e.g., /p/arjun-kumar) designed for recruiters.
  • Renders all cryptographic receipts, verified skill badges, GitHub AST telemetry,
    and company bounty trophies in a high-end presentation format.
  • Completely eliminates the need for paper resumes during recruitment drives.

5. DESIGN SYSTEM: LINEAR / RAYCAST STRICT MONOCHROME
--------------------------------------------------------------------------------
The UI is strictly styled according to minimalist, high-density SaaS principles:
  • Background:       Off-black #09090b (zinc-950)
  • Card Containers:  Flat g-zinc-900/50 with 1px solid order-zinc-800
  • Accent Color:     Single Emerald Green (#10b981 / emerald-500) reserved
                      solely for the primary Call to Action (CTA) and verified status dots.
  • Zero Purples:     Purged all purple/violet gradients, neon halos, and tech shadows.
  • Typography:       Dense scale with 	ext-[10px] uppercase font-mono tracking-wider
                      labels and large bold monospace metric values.
  • Micro-Details:    Keyboard shortcut tags (<kbd>1</kbd>-<kbd>9</kbd>, <kbd>⌘K</kbd>),
                      6px status dots, and clean 1px divider lines.

8. HOW TO RUN THE PROJECT LOCALLY
--------------------------------------------------------------------------------
1. Open PowerShell or Terminal and navigate to the project directory:
     cd C:\SIH

2. Install dependencies (if not already installed):
     npm install
     (or on Windows: npm.cmd install)

3. Start the Next.js development server:
     npm run dev
     (or on Windows: npm.cmd run dev)

4. Open your browser:
     http://localhost:3000

5. To run the production build check:
     npm.cmd run build
     npm.cmd run lint
